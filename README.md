На данный момент невозможно выбрать папку сохранения таблицы данных, а также расположение индекса в названи файла и отсутствует возможность обработать сразу несколько групп файлов без перезапуска программы, что возможно, будет добавлено в следующих версиях. 
Использовать программу рекомендуется через те варианты консоли, которые позволяют копировать и вставлять текст, например путь до нужной папки или строку после которой находятся данные.
